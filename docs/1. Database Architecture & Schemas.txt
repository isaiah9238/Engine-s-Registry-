3. Server-Side 768-Dimensional Vector Embeddings
Full-Stack Server (server.ts):
Mounted Express endpoint POST /api/embed using the official @google/genai SDK with outputDimensionality: 768.
Client vector service (src/services/vectorSearch.ts) supports Cosine Similarity K-NN ranking for:
Dynamic Semantic Tool Selection: Matches agent execution intents against the 768-dim skill vector space.
Memory Vector Recall: Retrieves semantic, episodic, and procedural records based on query similarity.
4. Interactive Studio & User Interface
"Vector & Memories" Studio View (src/components/VectorSearchStudio.tsx):
Dynamic Semantic Tool Selection: Enter an execution intent (e.g., "Audit cryptographic key vaults and enforce zero-trust ABAC"), generate a live 768-dim vector, and inspect ranked skill matches with similarity percentages, parameter schemas, and Cloud Storage bundle paths.
Cognitive Agent Memories: Filter memories by semantic, episodic, or procedural. Use the "Record Agent Memory" modal to embed new knowledge into Vector(768) on the fly and persist it to Firestore.
Cloud Storage Bundle Inspector: Select any skill to view, edit, and upload its guidelines.md and runtime.wasm / script.js directly to Firebase Storage.
